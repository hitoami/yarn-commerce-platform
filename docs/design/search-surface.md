# 搜索与首页内容区设计约束

来源：[Issue #22](https://github.com/hitoami/yarn-commerce-platform/issues/22)（2026-09-09）；搜索分组由 [Issue #131](https://github.com/hitoami/yarn-commerce-platform/issues/131) 2026-10-16 用户决定替换。行为与领域边界以 PRODUCT.md、CONTEXT.md 为准；本页记录当前视觉约束，不将候选稿写成 DESIGN.md。

## 当前方向（2026-10-16 用户决定，#131）

- 结果按「毛线 / 材料包 / 手工成品」三组同页展示。页顶标签「全部 / 毛线 / 材料包 / 手工成品」点击即切换显示的组并保留关键词，取代 2026-09 的「有成品、可买材料、仅灵感」筛选与「包袋、围巾、家居、玩偶」手绘分类。
- 视觉稿：Figma「hitoami 本地原型（#131）」[桌面 09 搜索结果 · 1440](https://www.figma.com/design/EBgAwtoSARIzOylhQFwkXY/hitoami?node-id=123-365) 与 [手机 10 搜索结果 · 390](https://www.figma.com/design/EBgAwtoSARIzOylhQFwkXY/hitoami?node-id=124-612)。图中商品、价格与材料包文案为构图演示，实际从 Shopify 与 `yarn_project` 读取。
- 毛线组在前，使用与毛线集合页相同的毛线卡（1:1 图、名称、规格、含税价格）。材料包组为图文横行（封面、名称、一句用途、约价与「教程在 LINE 领取」），进入材料包详情。手工成品组使用商品卡；真实成品上架前不出结果，标签显示「准备中」并置灰，只在结果下方说明一句。
- 无命中的组隐藏；三组都无命中时明确反馈并允许修改关键词，不把推荐内容计为命中。首次无关键词进入时提供输入与可编辑示例关键词。
- 搜索为独立页面，导航不高亮。手机沿用 2026-09 获批方案 3 的版式（[获批方向](approved/search-mobile-list.png)、[来源](approved/search-mobile-list.source.md)）：独立页头（返回 / 搜索 / 收藏）、58px 胶囊搜索框、清空 X 与输入区明确分开、标签为细下划线；分组顺序改为毛线在前。桌面标题、搜索框、标签与结果共用 1200px 内容轴并左对齐，不用居中窄搜索栏或弹窗筛选。
- 作品与商品的收藏保存于登录账号，跨设备可找回，具有统一入口；不把图标变色或本机临时保存当成功能完成。
- 暂不设计评分、评价数量或收藏人数，不虚构商品事实。

## 首页桌面内容区

- [获批视觉稿](approved/home-content-four-cards.png)及[素材来源与提示词](approved/home-content-four-cards.source.md)：2026-09-09 用户对修订稿回复「ok,好看」，作为本区域后续实现的构图依据。
- 2026-09-09 用户确认整体沿用暖纸图廊方向：搜索与手绘分类并排，作品精选采用四列、上图下文的卡片。
- 精选成品复用作品精选的卡片构图，同样每行四张；图片、名称、简介、收藏位置和尺寸保持一致，不另设横向图文卡片样式。
- 成品区用一块外层浅色背景区分；卡片原本的能力标签位置改为深色、克制字号的价格，不同时保留能力标签。实际商品与价格来自 Shopify，视觉稿演示内容不代表上架或库存事实。

## 首页 Hero 的固定边界

- 2026-09-09 已直接核对 Shopify 当前 yarn-commerce-platform/main 主题 189684220217 及最新 origin/main 的 Hero 实现。
- 主标题保持「从喜欢的作品，开始你的手作。」；说明保持「毛线、用量、工具与教程，跟着作品慢慢准备。」；按钮保持「发现作品」。
- 保留「选作品 → 挑毛线 → 找工具 → 看教程」四个手绘节点、毛线连接路径及下方波浪。来源是 sections/yarn-hero.liquid、templates/index.json 和实际引用的 mewool-hero-*-node 图片。
- 本次桌面调整仅涉及 Hero 下方搜索、分类、作品与成品区域；不得使用旧手提包摄影 Hero、改写标题或重排整个品牌首屏。
- 候选稿和检查产物仅在被忽略的本地目录按需保留。上述构图是用户确认的方向；本轮 Theme 与服务代码由 Issue #39 承接，安装、部署与验收状态以该 Issue / PR 为准。
