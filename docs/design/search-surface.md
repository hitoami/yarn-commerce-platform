# 搜索与首页内容区设计约束

来源：[Issue #22](https://github.com/hitoami/yarn-commerce-platform/issues/22)，2026-09-09 用户确认。行为与领域边界以 PRODUCT.md、CONTEXT.md 和作品体验合同为准；本页记录当前视觉约束，不将候选稿写成 DESIGN.md。

## 当前方向

- 手机搜索沿用用户选择的方案 3：[获批方向](approved/search-mobile-list.png)及[来源](approved/search-mobile-list.source.md)。作品图文横行，商品两列图卡；暖白纸面、手绘分类、细线图标与克制的陶土色。
- 搜索为独立页面，首页导航不得高亮。手机搜索栏采用胶囊形，清空 X 与独立滑杆筛选按钮必须明确区分。
- 分类沿用首页「包袋、围巾、家居、玩偶」及对应手绘图标，搜索页增加「全部」；类别按实际内容扩展。
- 作品卡显示名称、一句用途简介、实际购买能力及爱心；商品卡显示名称、简短说明、适用规格、深色适中字重的价格及爱心。难度、时间等仅在适用且有依据时显示。
- 作品与商品的收藏保存于登录账号，跨设备可找回，具有统一入口；不把图标变色或本机临时保存当成功能完成。
- 暂不设计评分、评价数量或收藏人数，不虚构商品事实。

## 搜索与首页分工

- 首页提供精选及分类浏览；统一搜索页用于输入关键词和按条件查找。
- 首次无查询进入搜索页提供输入、分类及可编辑示例关键词；从首页「查看全部」进入时直接显示对应作品浏览，不绕回空入口。
- 简单筛选沿用「全部、有成品、可买材料、仅灵感」，类别不在面板重复。筛选保留关键词，同页展示适用的作品与商品结果，隐藏无命中组。
- 首页作品使用较大图片并复用同一份简介、能力与收藏状态。独立成品区使用 Product 商品卡及商品详情入口，不让作品卡随筛选静默变成商品链接。

## 搜索桌面布局（2026-09-09 用户反馈）

- 用户指出居中窄搜索栏与弹窗筛选像移动端，要求借鉴所给参考的桌面横向空间组织；保留当前手作视觉系统。
- 标题、搜索工具栏、分类与结果共用内容区边界；搜索和「全部、有成品、可买材料、仅灵感」常驻筛选横向排列，点击立即应用。空间不足时整组换行，不缩小文字或挤窄搜索。
- 分类独占一整行，手绘图与名称左右排列；默认示例关键词也跟随左边界。参考仅用于操作区布局，不引入表格、侧栏或额外业务筛选。
- 手机维持获批构图和底部筛选面板；桌面与手机共享同一购买条件、查询和返回状态。

## 首页桌面内容区

- [获批视觉稿](approved/home-content-four-cards.png)及[素材来源与提示词](approved/home-content-four-cards.source.md)：2026-09-09 用户对修订稿回复「ok,好看」，作为本区域后续实现的构图依据。
- 2026-09-09 用户确认整体沿用暖纸图廊方向：搜索与手绘分类并排，作品精选采用四列、上图下文的卡片。
- 精选成品复用作品精选的卡片构图，同样每行四张；图片、名称、简介、收藏位置和尺寸保持一致，不另设横向图文卡片样式。
- 成品区用一块外层浅色背景区分；卡片原本的能力标签位置改为深色、克制字号的价格，不同时保留能力标签。实际商品与价格来自 Shopify，视觉稿演示内容不代表上架或库存事实。

## 首页 Hero 的固定边界

- 2026-09-09 已直接核对 Shopify 当前 yarn-commerce-platform/main 主题 189684220217 及最新 origin/main 的 Hero 实现。
- 主标题保持「从喜欢的作品，开始你的手作。」；说明保持「毛线、用量、工具与教程，跟着作品慢慢准备。」；按钮保持「发现作品」。
- 保留「选作品 → 挑毛线 → 找工具 → 看教程」四个手绘节点、毛线连接路径及下方波浪。来源是 sections/yarn-hero.liquid、templates/index.json 和实际引用的 mewool-hero-*-node 图片。
- 本次桌面调整仅涉及 Hero 下方搜索、分类、作品与成品区域；不得使用旧手提包摄影 Hero、改写标题或重排整个品牌首屏。
- 候选稿和检查产物仅在被忽略的本地目录按需保留。上述构图是用户确认的方向；本轮 Theme 与服务代码由 Issue #39 承接，安装、部署与验收状态以该 Issue / PR 为准。
