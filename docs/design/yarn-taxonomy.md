# 毛线分类

2026-11-19 锦晨确认。依据：选品表「录入-毛线资料」的 39 款毛线。

## 原则

- 只有一套数据：导航、毛线目录、首页吊牌、搜索页都读 `snippets/yarn-facets.liquid` 算出的标记。
- 快捷入口（首页吊牌、搜索分类、导航「推荐」栏）只是下面字段的筛选组合，不新开字段。
- 一个入口至少 8 款。不到 8 款的不做入口，做成卡片小标记或并进相近的一项。

## 第一层：毛线本身的属性

| 分组 | 选项 | 标记 | 来源 |
|---|---|---|---|
| 粗细 | 轻柔细线 / 粗细适中 / 蓬蓬粗线 | `thick:fine / medium / chunky` | `yarn.thickness`，照选品表「粗细」列填：特粗、超粗、粗 → 蓬蓬粗线；中粗（含「中粗（蓬松）」等）→ 粗细适中；中细、细、超细 → 轻柔细线。没填时按每 100g 米数：≤200m 粗、≤350m 适中、其余细 |
| 花色 | 纯色 / 段染渐变 | `color:solid / variegated` | `yarn.color_type`；段染、渐变、混色、彩虹色都算段染渐变 |
| 材质 | 羊毛 / 羊毛混纺 / 棉 / 合成纤维 | `fiber:wool / wool_blend / cotton / synthetic` | `yarn.composition`：全是羊毛、美利奴、羊驼 → 羊毛；含这些或马海毛 → 羊毛混纺；棉 ≥50% → 棉；其余 → 合成纤维 |
| 克重 | 50g 以下 / 51–149g / 大团（150g 以上） | `grams:small / mid / big` | `yarn.ball_weight_g`；只在目录筛选抽屉里 |

## 第二层：想织什么

毛衣 / 帽子 / 围巾 / 毯子 / 包包 / 玩偶（`works:*`，`yarn.works` 多选）。「新手」不放在这里。

## 第三层：快捷入口

| 入口 | 标记 | 来源 |
|---|---|---|
| 新手推荐 | `beginner:yes` | 填了 `yarn.beginner_reason`（中粗到粗、线条光滑、看得清针目；不选毛茸茸、圈圈、亮片） |
| 渐变段染 | `color:variegated` | 花色 |
| 毛茸茸 | `feature:fluffy` | `yarn.fluffy` 为真（绒线、雪尼尔、皮草线、羽毛线、马海毛） |
| 轻柔细线 | `thick:fine` | 粗细 |
| 钩针用线 | `feature:crochet` | `yarn.crochet` 为真（文案写明钩织的、包包线、蕾丝线、玩偶线） |
| 大团毛线 | `grams:big` | 克重 |

首页吊牌就是这 6 个，还没有商品的也显示，带「准备中」小标签、照片位放小图标（锦晨 2026-11-19）；导航「毛线分类」第 4 栏「推荐」放新手推荐、毛茸茸、钩针用线、大团毛线（另外两个已在粗细、花色栏里）。目录网址用 `ycb_beginner=1`、`ycb_feature=fluffy|crochet`、`ycb_<组>=<值>`。

## 卡片小标记

- 白胚 · 可自己染：`yarn.undyed` 为真（039-1 至 039-4 这 4 款未染色白胚线）。
- 手染线以后到 8 款以上再考虑做入口。

## 店铺里要建的商品字段（`yarn` 命名空间）

| 字段 | 类型 |
|---|---|
| `thickness` | 单行文字（照选品表原文填） |
| `fluffy` | 真 / 假 |
| `crochet` | 真 / 假 |
| `undyed` | 真 / 假 |

`color_type` 新上架的只选「纯色」或「段染渐变」。旧字段 `yarn.texture`、`yarn.use` 还有几处在读（旧的首页圆图、详情页、加购推荐、搜索商品卡、页头），这些改完再删。
