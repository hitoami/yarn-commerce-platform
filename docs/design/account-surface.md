# 登录、个人资料、订单与收藏

模式：Operate（完成登录、管理商业资料、找回收藏）。关联 Issue #344。

## 获批方向

锦晨 2026-11-11 确认[账户手机稿](approved/344-account-mobile.png)，并明确要求按该方向完成手机和桌面、直接提交 PR 预览。桌面沿用同一视觉系统，收藏保留全站页头与宽版商品网格。

首页的暖白背景、陶土强调、圆润字体、现有 hitoami Logo 是共用依据。收藏按品牌页头、标题、本机保存提示、分类、内容或猫咪空状态、帮助入口排列。复用现有 token、商品卡和收藏逻辑。未配置官方 LINE 时，显示「联系店员」并进入联系页。

## 两种实现边界

- Theme：`sections/yarn-search.liquid` 的 `browse=favorites` 状态由 `assets/yarn-account.css` 适配。手机用紧凑品牌页头，桌面用共享导航；有搜索词时保留清空入口。普通搜索仍沿用搜索页结构。账号浮层消费相同颜色与圆角 token。
- Shopify 托管账户：登录、个人资料、地址和订单的布局、表单、认证方式由 Shopify 管理。通过结账与账户编辑器的**未发布配置草稿**调整 Logo、配色和可选字体；Theme CSS 不能覆盖这些页面。配置与结账共用，发布须单独核验结账并获批准。

本次草稿 `10247700793` 使用仓库的 `hitoami-logo-600.webp`，宽 180 px、居中；主要背景 `#FFFDFA`、强调及按钮 `#A6472E`，标题与正文选择编辑器提供的 Zen Maru Gothic 圆体。编辑器没有首页的完整分语言字体栈，不能把该选择描述为中文 Huninn / 英文 Nunito 已接入托管页。托管布局、文字色、空状态及表单内容以实际编辑器预览为准，不保证与稿逐像素一致。

收藏仍按当前浏览器保存；没有部署跨设备同步。保留 Shop、Google 与邮箱认证配置，不修改营销默认勾选、真实资料、订单或支付。编辑器里的示例姓名、地址、余额和订单只供模拟预览，不是店铺事实，也不进入 Theme。

## 预览与验收

Theme 在 PR 未发布预览打开 `/search?browse=favorites`；中文线上路径为 `/zh/search?browse=favorites`，本地代理中文为 `/search?browse=favorites`。账户样式从 Shopify 后台「设置 → 结账 → 配置」进入草稿，在顶部切换登录、订单、资料和手机/桌面。

必要检查：`npm run verify`、完整 `npm run proof`，收藏空状态、真实收藏/分类/取消收藏、日中英 390/1440 截图与导航。认证成功、真实资料保存、支付与真机检查不能用编辑器模拟数据替代。实际结果和未通过项只记在 PR，不将过程截图提交到仓库。
