# 毛线详情手机方向与来源

- 关联：[Issue #120](https://github.com/hitoami/yarn-commerce-platform/issues/120)。用户 2026-10-02 在会话中要求按此视觉稿实现，并逐项确认下列冲突。
- 视觉稿：Claude Design 项目 `640bf57a-59c1-4693-978d-bc7e33c124e9`（UI mockups request）中的 `Yarn PDP.dc.html`，方案 1a「常规：按信息块顺序排列，团数计算放在规格之后」，390 × 844 简体中文。组件来自同项目的 hitoami yarn design system（`_ds/hitoami-yarn-design-system-cff99daf-…`）。
- 视觉稿中的商品名、价格、色名、团数、针号、洗涤说明、作品与编织包都是 demo；实现只读 Shopify 数据，见 [surface brief](../product-detail-surface.md#毛线详情手机版issue-120)。

## 用户确认（2026-10-02）

| 冲突 | 决定 |
|---|---|
| 手机常驻购买栏 vs 旧方向「不使用浮动购买栏」 | 保留；原加购区仍在，常驻栏在其滚出视口后出现 |
| 视觉稿焦糖棕 `#7b5a3b`（设计系统方案 C 层，未进 `colors.json`）vs 奶油黄加购 + 陶土红价格 | 按视觉稿，复用已有 `home-action` 灰棕；仅毛线详情页，编织包 / 成品详情页暂不变 |
| 标题 24px 中粗炭黑、主图 1:1 + 4 缩略图 vs 26px 粗体藏青、3:2 + 3 缩略图 | 按视觉稿；主图完整显示不裁切 |
| 手机页内加购（2026-10-04，#122） | 按视觉稿去掉，常驻栏始终显示，取代上一行「原加购区仍在」；「购买须知」与相关商品保留在洗涤之后 |
| 「要买几团？」「怎么洗」无后台字段 | 新建 `yarn_usage` 内容类型与 `yarn.usage_estimates` / `yarn.care` 商品字段，有数据才显示；演示数据只写 Joyful Cake Yarn |

## 与视觉稿的差异

- 颜色：真实 Variant 没有色值，显示为色号圆钮（如 A01）；有 Shopify 色板时显示色块。
- 规格：只显示已录入字段，密度与棒针 / 钩针分开的推荐针号暂无字段，不显示。
- 「用这款线能织」副标题改为「用到这款线的作品。」，「搭配的编织包」不写「线、针和图解都配齐了」：两者在数据上都未核实。没有编织包配对时不显示。
- 「查看全部」暂无作品库入口，不显示。
- 「（含税）」只在 Shopify 含税设置开启时显示；2026-10-04 店铺设置为不含税，与公告条「含税」文案不一致，待运营核对。
- 洗涤每行统一用洗涤图标；视觉稿各行图标不同但无数据对应。
