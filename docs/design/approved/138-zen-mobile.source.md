# #138 Zen 手机首页方向与交接

## 批准与范围

2026-10-15，用户比较中、英、日真实字体与固定 Logo 的四套方案后确认「Zen 可以的」，随后同意沿用该方案，并要求复用 PR #139，先由 Claude Design 做设计，再由 Codex 实现手机预览。

本次模式为 Persuade。沿用 [#131 当前首页构图](131-mobile.source.md)、原 Logo、手作小屋 Hero、实物分类与独立小猫，调整字体、颜色和必要的阅读层级。手机页面实现仍需用户查看后确认；本文件不表示桌面视觉或生产发布已验收。

## 设计与实现职责

[Claude Design · Zen 手机首页](https://claude.ai/design/p/b663ad8b-0666-4fb4-93b8-0cb4d588ebc8) 负责 390px 设计与交接；输入包括当前首页首屏、品牌 / 分类、真实商品卡的手机截图，以及用户提供的配色参考。Codex 依据该设计接入现有 Shopify Theme，保留 Liquid 数据来源和原生交互。

手机设计优先检查 390px，并兼容 320px。具体字号、间距和控件尺寸以完成后的设计交接与 Theme 实测为准；基线文档数值不自动成为新稿尺寸。设计与 Theme 的当前完成状态、待验收差异和验证证据只记录在 [Issue #138](https://github.com/hitoami/yarn-commerce-platform/issues/138) / [PR #139](https://github.com/hitoami/yarn-commerce-platform/pull/139)。

## 交接来源与适用范围

Claude 项目中的 `index.html`、`zen-home.css`、`zen-home.jsx`、`zen-data.js` 与 `handoff.md` 为本次设计来源。设计已补入当前首页八件商品的真实图片、名称、规格及未开售状态，并按当前 Shopify 菜单核对五个主入口。预览中的英日暂译和静态链接仅供设计审阅；Theme 继续读取 Shopify 与 Theme locales。

手机结构沿用 #131，重点为同族字体、40–48px 分区留白、88px 圆形分类、两列完整商品标题、小号未开售状态及 56px FAQ 行。Hero 使用原响应式高度、三张原图与手动切换。Logo 保留原透明资产，取消 CSS multiply 叠色。

Theme 复用原生菜单开关、焦点管理、语言下拉与订阅表单；不会为复制静态稿而创建第二套交互。共享字体和颜色通过原 token 文件接入，手机版式规则限定于当前首页。桌面新稿与整页人工验收仍按既定顺序推进，不由本次手机预览代替。
