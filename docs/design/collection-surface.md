# 毛线目录页

模式：Browse。让顾客按手感逛毛线，看清规格与价格后进入商品详情。与搜索的分工见 [搜索 surface brief](search-surface.md)：目录负责「逛」，搜索负责「找」，两者共用同一张毛线卡与商品详情。

## 当前批准范围（2026-11-20 分类页，取代 #85 / #209 / #366 的胶囊版）

锦晨 2026-11-20 看过 [样稿 v2] 后选定：顾客几乎都是带着一个入口进来的，目录页要先展开他选的，再让他切换和细筛（参考 hoshiami 的「每个入口一个页面」和 Hobbii 的圆图切换）。先用同一个 `/collections/yarn` 按入口换标题，不建独立集合。

- 顺序：面包屑（首页 / 毛线 / 入口）→ 标题与说明（入口的，无入口时用集合本身的）+ 右侧「共 N 款 · 价格含税」→ 一排圆图 → 细筛行 → 毛线卡（手机 2 列、平板 3 列、桌面 4 列）→ 「放宽一个条件」（结果少于 4 款时）→ 「已显示 N / 总数」与「显示更多」→ LINE 紧凑帮助条。
- 入口 = 网址里第一个 `ycb_*` 参数（导航、首页、搜索、圆图都只带一个）；JS 写网址时把入口那一组排在最前面，重开或分享仍认得。入口的三语标题、说明、圆图在主题编辑器「入口」区块维护；没有区块的入口用筛选名做标题、不显示说明。
- 圆图：只在粗细 / 花色 / 材质 / 织什么入口出现，列出入口所在组的全部分类（「全部毛线」和新手入口没有同组可切换，不显示圆图；锦晨 2026-11-20：全部毛线下出现「按织什么切换」不合逻辑），前面加「全部毛线」，当前项加深色外圈、带款数；点击就地切换并清掉细筛。图优先用入口区块上传的图，否则取这一类第一款毛线的卡片图（织什么入口建议上传作品照）。
- 细筛：开关只写「筛选」（锦晨 2026-11-20：不用列出各组名），分类入口默认收起、全部毛线默认展开；展开后入口所在组以外的每组一行（粗细、花色、材质、织什么、克重、特点，只列有商品的值；新手推荐只有一个选项，放在「特点」一行最前面），同一行多选取并集、不同行取交集，款数是其他已选条件下还剩几款，0 款变灰不可点。手机上每行左右滑。
- 手感地图、顶部胶囊、「列表 / 地图」切换和详情页「在手感地图上看」已删除。
- 价格带与现货仍是 Search & Discovery，放在「价格 · 库存」抽屉，提交后刷新页面。
- 一次渲染至多 48 款，浏览器里每次露出 12 款；没有 JS 时直接列出全部。超过 48 款时 JS 先载入其余页再筛。
- 商品卡沿用 `yarn-pick-card`（`clean_title`、`card_line`）。集合还没有商品时显示「准备中」占位卡，不含商品名、价格或库存。
