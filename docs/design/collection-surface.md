# 毛线目录页

模式：Browse。让顾客按手感逛毛线，看清规格与价格后进入商品详情。与搜索的分工见 [搜索 surface brief](search-surface.md)：目录负责「逛」，搜索负责「找」，两者共用同一张毛线卡与商品详情。

## 当前批准范围（#85）

- 手机：用户 2026-10-17 在会话中确认按 Figma「hitoami 本地原型（#131）」[06 毛线集合页 · 390](https://www.figma.com/design/EBgAwtoSARIzOylhQFwkXY/hitoami?node-id=120-383) 实现。桌面稿「05 毛线集合页 · 1440」尚待确认，当前桌面实现只做 4 列的可用版。
- 顺序（平板 / 桌面）：面包屑 → 「共 N 款 · 价格含税」 → 集合标题与集合说明 → 一排胶囊 → 筛选 / 排序 / 款数 → 毛线卡（平板 3 列、桌面 4 列）→ 「已显示 N / 总数」与「显示更多」→ LINE 紧凑帮助条。
- 手机首屏（#209，用户 2026-10-29 批准每日提案 #1，[Figma 对比稿](https://www.figma.com/design/9wLXRfi42BhU4fFYmReJAn)）：第一行为标题 + 「共 N 款 · 价格含税」（muted）+ 右侧无边框排序；第二行为 44px 圆形筛选图标 + 横滑胶囊（44px 高、34px 小图，#366）；随后直接是 2 列毛线卡，卡上不重复「毛线」小标签（保留色数；成品集合不变）。集合说明与面包屑移到「显示更多」之后。不再单独显示筛选排序行和重复的款数。卡片照片铺满 1:1 方框（`cover`），是 `DESIGN.md` 照片 `contain` 规则的例外，用户 2026-10-29 决定。
- 筛选只有一套（#366），与页头导航（#355）同源：每张卡带 `yarn-facets` 标记，粗细 3 档（轻柔细线 / 粗细适中 / 蓬蓬粗线）、花色、材质、织什么、克重（含大容量）、新手友好都在浏览器里筛，网址 `ycb_*`；价格带与现货是 Search & Discovery，提交后刷新。导航点进来与在页面里点同名胶囊结果相同。
- 顶部常驻一排胶囊：全部 / 新手友好 / 粗细 3 档，名字与导航一致并带款数。款数、选中状态、「共 N 款」、「已显示 N / 总数」与「显示更多」都按当前筛选算；当前条件下没有商品的胶囊变淡。旧的 Search & Discovery 分类胶囊、5 档粗细面板和「全部分类」已去掉。
- 首页圆图、详情页「同类毛线」带来的 `filter.p.m.yarn.texture` / `yarn.use` 照常由 Shopify 筛选，显示为胶囊下可清除的标签。
- 一次渲染至多 48 款（目录现有 35 款），浏览器里每次露出 12 款；没有 JS 时直接列出全部。超过 48 款时 JS 先载入其余页再筛。
- 手感地图（#243）的三行与粗细胶囊同一套分档，详情页「在手感地图上看」只在有克重和米数时出现。
- 「筛选」抽屉（手机从底部升起，桌面靠右）：粗细、花色、材质、织什么、克重（只列当前商品里有的值，带款数），再加 Search & Discovery 开启的现货与运营设置的价格带；没有数据的筛选不显示，不留空壳。
- 商品卡沿用首页 `yarn-pick-card`；未定价显示「暂未开售」。集合还没有商品时显示「准备中」占位卡（DESIGN.md 成品区规则），不含商品名、价格或库存。
- 标题与说明来自 Shopify 集合本身，不在主题里另写营销标题；与视觉稿标题文字不同属于有意取舍。
