# 毛线项目视觉实施与评审

UI / UX 工作读取本文件。范围、数据归属与生产授权以根目录 `AGENTS.md` 为准。本文的页面设计流程覆盖 Impeccable reference 中的 Comp-first 关卡、方向轮选（`concept-seed`）、`build-phase` 与独立 finish review 要求；这些步骤仅在用户明确要求时使用。

## 页面设计流程（2026-09-26 用户决定，#69）

设计仍会推倒重来，流程以省 token 为先。一个页面由一个带生图能力的 Codex 线程从视觉稿、实现到自查做完，不拆给多个 agent。

1. **手机稿**：生成一张手机构图稿。输入必须把当前站相关页面截图和参考站截图作为图片传入（只写路径不算；生图最多 5 张参考图，挑最相关的）。不出多方案。
2. **手机实现**：用户确认手机稿后实现手机版，截图给用户确认。
3. **桌面稿与实现**：手机版确认后，再以手机实现截图和参考站桌面截图为输入出一张桌面稿；用户确认后实现桌面版。手机与桌面分开走，不并行。
4. **稿子管什么**：视觉稿是构图合同，区块顺序、卡片形态、图文比例按稿实现；尺寸、字号、间距以实现后的 390 / 1440 截图为准，不要求生成图达到真实像素。稿中没有真实素材或数据支撑的内容不实现、不伪造。
5. **冲突要问**：稿与 `DESIGN.md` / token 冲突（价格色、标题字重、图片比例、标签等）时列出冲突问用户，不自行回退旧值。
6. **不设评审关卡**：设计阶段不做独立视觉评审和多轮走查；用户看实现截图决定。
7. **先查证再改**：店名、域名、市场配置等牵连后台和素材的决定，先在 Issue 附查证结果（商标、域名等）再改代码；颜色和字体可直接改。

## 截图与自查

- 自查用 `npm run proof`：先在另一个终端运行 `npx shopify theme dev --store tutaka-54.myshopify.com --live-reload off`，再跑 `npm run proof`。它检查日文 `/ja`、简体中文 `/`、英文 `/en` 的关键页面（路径以当前店铺与 `scripts/proof.config.cjs` 为准）的主题侧语言泄漏、横向溢出、图片加载与脚本异常，并生成 390×844 / 1440×900 首屏截图和清单 `.proof/report.md`（被忽略，不提交）。页面与选择器在 `scripts/proof.config.cjs` 维护。
- 只改了少数页面时可以缩小范围：`npm run proof -- --pages yarn-pdp --viewports mobile`；PR 前跑一次完整的。
- 发布后查线上：`PROOF_BASE_URL=https://hitoami.com npm run proof -- --live`。`--live` 改用线上语言路径（日文 `/`、中文 `/zh`、英文 `/en`）；浏览器语言按页面语言设置，不会被店铺的语言重定向带走。
- 只打开与本次改动相关的截图；不看整页长图（读取时会被缩到一两百像素宽）。对照视觉稿时同视口并排看；上下文压缩后先重新打开视觉稿与 Issue。
- 「内容层混语言」来自 Shopify 后台内容（商品名、描述、菜单等），归 #60 / #68，不阻塞主题改动；新写的主题文案若被列进这一节，说明选择器写宽了，改 `scripts/proof.config.cjs`。
- `npm run proof` 不覆盖的仍需手动看：手机展开菜单、页脚与当前页语言一致，不把缺失译文的英文回退当通过；交互流程（筛选、规格、加减购物车）按改动范围实点。
- 视觉改动另跑 `.agents/skills/impeccable/scripts/impeccable detect <changed-ui-files>`，只针对本次文件。
- 自查一轮集中修复，第二轮确认后停止；未通过项修复或如实报告。PR 简记检查结果与未解决项，不附逐轮记录。

## 评审图片

- AI 生成的视觉稿、示意图和带标注截图，画面内可读文案一律使用简体中文，不因面向日本市场改用日文；品牌名、正式产品名和代码标识符除外。
- 生成前在提示词中逐条列出准确简体中文文案，并禁止日文、乱码和额外文案。日文市场内容在方向获批后进入 Shopify 可编辑的本地化层，不烘焙进图片。
- 生成后打开原图核对文字。出现日文、不可读文字、错字或模型自造标签的图片无效，重新生成后再给用户看。
- 发布用 raster 记录提示词或来源；未授权参考图仅用于受保护的内部原型，不进入公开 diff。
- 用户确认的视觉稿与来源放 `docs/design/approved/`，由对应 surface brief 引用；确认后的实现规范更新到 `DESIGN.md`，不复制讨论经过。
