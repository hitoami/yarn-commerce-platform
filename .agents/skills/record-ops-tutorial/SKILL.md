# 中文实操视频

交付让同事能够照着操作的真实录屏：知道从哪里进入、改了什么、何时保存、去哪里看结果。业务链路演示还要说清楚哪些只在测试条件下成立、真实营业还缺什么。

制作依据：2026-10-24 用户确认的录屏样片及后续教程要求，见 [#200](https://github.com/hitoami/yarn-commerce-platform/issues/200)、[#201](https://github.com/hitoami/yarn-commerce-platform/issues/201)、[#202](https://github.com/hitoami/yarn-commerce-platform/issues/202)。这些任务提供制作依据，不能当作当前店铺状态或新的操作授权。

## 开始时确定

- 从当前请求和已有样片确认受众、目标操作、章节、语言与交付位置。用户已认可形式或已批准继续制作时直接沿用，不重复申请样片确认；用户明确要求「先样片，再整套」时在该节点等反馈。
- 每节用一行定义：**从哪里进入 → 做什么 → 画面怎样证明成功 → 怎样恢复**。经营演示再加「仍未验证的现实环节」。不为了凑教程把查看入口说成实际修改。
- 列出会触及的字段、库存规格/地点、订单或通知，以及原值、演示值、恢复办法。制作视频本身不授权修改店铺、真实交易或对外发送；沿用会话中已有的明确授权，只问缺失部分。
- 涉及 Shopify 时按需读 [业务边界与恢复](references/shopify.md)。使用当前仓库产品定义和当前页面；不复用历史商品、窗口、订单或主题 ID。
- 开始录制前读 [录制、配音与剪辑](references/production.md)，包含已跑通的 macOS 录制方法和容易损坏成片的细节。

## 先证明能录，再操作

1. 确认浏览器与账户。默认沿用用户的外部 Chrome；若需要回退，先说明。UI 操作使用当前可用浏览器工具及其文档，不绕过工具控制限制。
2. 核对目标窗口、录屏权限、前台页面和画面范围。先做数秒无业务改动的录制，检查实际点击、输入是否出现在视频中。权限不足或窗口不可见时让用户完成必要操作，不能用截图轮播冒充录屏。
3. 提前处理无关标签、书签、私人通知、凭证和真实客户信息。保留必要导航，避免为了隐私裁切把入口或保存按钮一起切掉。无法得到安全且可读画面时改用已授权的测试内容。
4. 第一次修改前记录精确基线；每次改变外部状态后读取成功提示，并核对实际结果。录制失败也先核对并恢复业务状态，再决定是否重录。

## 每节的操作结构

| 片段 | 必须看得清的内容 |
|---|---|
| 进入 | 后台首页或合理起点、菜单、搜索、目标条目；不只从已打开的编辑框开始 |
| 核对 | 名称、规格、语言、地点等足以避免操作错对象的信息 |
| 操作 | 真正的点击和输入；保存前能看清最终值 |
| 保存 | 按钮动作与成功提示，不能只录到点击就说已保存 |
| 结果 | 刷新后的对应网站页面或顾客订单页，目标规格/语言与后台一致 |
| 恢复 | 撤销本次演示改动、再次保存、刷新后复核；适用时查看调整历史 |

录制期间记录关键动作时间，至少包含开始输入、保存、保存成功、网站变化、恢复保存、恢复复核。临时记录只留在任务本地，用来对齐声音和剪辑。

可剪短加载、无关等待和未保存的误输入，但必须保留证明真实操作的前后关系。若发生已保存的错误或未解决的问题，先处理和核实，不能用剪辑伪装成成功。教学卡片可解释分工或待办，要明确标注「示意」「待确认」或「未验证」。

## 中文讲解与字幕

- 先看实际素材，再写讲解。沿着「现在做什么 → 为什么 → 看哪里确认」讲，不朗读整页，不把计划写成已完成事实。
- 配音按动作片段生成；旁白说「输入」「保存」「已恢复」时，画面必须分别出现对应动作或证据。修剪后重新计算时间，不能沿用原录屏时间。
- 语音偏长时先缩短句子，再适度延长该操作片段；不要为了放完讲解拉长无关空白。动作之后的停留可用于解释，但不能让讲解指向错误画面。
- 字幕烧进视频，另附 SRT；按词边界或实测语音时点切分，不按平均字数猜整段时间。换行按中文字体实际宽度测量，不能挡住输入框、保存按钮或结果。
- 日文界面必要文字旁附中文解释。视频中的角色、物流或收款结论只能来自本次实际证据。

## 验证与交付

技术验证和业务核对分别完成：

- **文件**：最终 MP4 可完整解码；分辨率、帧率、画面比例、音轨及总时长符合约定。检查拼接处声音、字幕和画面是否逐渐错位。
- **可读性**：抽看各节入口、输入、保存、网站变化、恢复等关键帧，并播放这些片段及剪辑接缝。缩略图只能辅助定位，不能代替原尺寸查看和听音。
- **状态**：恢复后重新读取后台并刷新网站；库存检查当前数量和期间变动，订单核对取消/退款/履约与库存。做不到的部分明确列为未完成。
- **交付**：MP4、同名 SRT、简短观看说明（章节时点、必要剪辑说明、测试条件与未验收项）。在回复中直接展示可播放视频与文件链接；不把过程日志、原始录屏和私人数据混入交付包。

用户要求同步 Slack 时，沿用已确认频道和受众，发一条中文消息：目的、每条视频与时长、已验证/未验证、需要团队确认的分工或下一步。附视频，等上传处理完成再发送；核对已发布消息和全部附件，能取得时返回消息链接。没有发送授权时只在当前聊天交付，不自行群发。

完成后按 AGENTS.md 更新对应 Issue / PR 的交付与未完成项。只保留当前有效制作说明；录屏、字幕中间文件、截图、检测 JSON 和时间记录不提交仓库。没有进行的检查不要写成通过。
