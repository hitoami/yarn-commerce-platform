# 编织术语中日对照

翻译时先查本表，表里没有的词才自行翻译，并在 PDF 的「审校要点」里标出来。日文后附读音（罗马音）。
「⚠️」= 容易翻错；「?」= 未经日本编织者确认，以人工审校为准，确认后去掉问号。

## 规格换算

- **钩针号数**：日本写「○/0号」，数字越大针越粗（5/0 号 = 3.0mm，6/0 号 = 3.5mm，7/0 号 = 4.0mm）。PDF 里同时写 mm 和日本号数，例如「3.5mm（6/0号）」。
- **棒针号数**：日本数字越大针越粗（6 号 ≈ 3.9mm，10 号 ≈ 5.1mm）；中国老式号数方向相反。只以 mm 为准换算。
- **线材粗细**：中文「4 股 / 8 股」和日本「合太 / 並太」没有严格对应。写明成分、每团克数和米数、推荐针号，粗细档位标「?」，交人工确认。
- **牛奶棉**：日本也叫「ミルクコットン」（milk cotton）。
